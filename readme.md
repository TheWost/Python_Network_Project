# Python TCP socket server & server example


Very very simple, multi device TCP socket application built in Python for real-time network communiaction


## Prerequisites

- **Python 3.x** installed


## Configuration

**Server Host** `0.0.0.0`
**Client Host** `127.0.0.1`
**Port** `5000`



## How to run

### Option 1: testing on the same computer (two terminals)
1. **Start the Server**:
python3 server.py
2. On other terminal **start the client**:
python3 client.py
